================================================================================
GUIDE: SETUP LIBRARY PROJECT ON RASPBERRY PI (Model 3B / 3B+)
================================================================================

Этот скрипт-гайд поможет настроить среду для запуска C++ Backend и Flutter Frontend.
Raspberry Pi 3 может работать как на 32-битной, так и на 64-битной ОС.
Flutter и библиотеки должны строго соответствовать разрядности вашей системы.

ШАГ 1: ОПРЕДЕЛЕНИЕ РАЗРЯДНОСТИ СИСТЕМЫ
--------------------------------------------------------------------------------
Откройте терминал на Raspberry Pi и выполните команду:

    uname -m

Смотрим на результат:
- Если вы видите: aarch64  -> У вас 64-битная система (ARM64). Следуйте разделу А.
- Если вы видите: armv7l   -> У вас 32-битная система (ARM32). Следуйте разделу Б.

================================================================================
РАЗДЕЛ А: ИНСТРУКЦИЯ ДЛЯ 64-БИТНОЙ СИСТЕМЫ (aarch64)
================================================================================

1. Обновите систему и установите базовые зависимости:
   sudo apt update && sudo apt upgrade -y
   sudo apt install -y git curl unzip xz-utils zip libglu1-mesa \
       libgtk-3-0 libblkid1 liblzma5 libgl1-mesa-glx \
       cmake g++ libpq-dev postgresql-client clang llvm pkg-config ninja-build

2. Увеличьте Swap-файл (ОБЯЗАТЕЛЬНО для Pi 3 с 1GB RAM):
   sudo nano /etc/dphys-swapfile
   # Найдите строку CONF_SWAPSIZE=100 и замените на CONF_SWAPSIZE=4096
   # Нажмите Ctrl+O, Enter, затем Ctrl+X
   sudo /etc/init.d/dphys-swapfile stop
   sudo /etc/init.d/dphys-swapfile start

3. Скачайте Flutter SDK для Linux ARM64:
   cd ~
   wget https://storage.googleapis.com/flutter_infra_release/releases/stable/linux/flutter_linux_3.24.0-stable.tar.xz
   tar xf flutter_linux_3.24.0-stable.tar.xz
   
   # Добавьте в PATH
   echo 'export PATH="$PATH:$HOME/flutter/bin"' >> ~/.bashrc
   source ~/.bashrc

4. Включите Desktop поддержку:
   flutter config --enable-linux-desktop
   flutter doctor

================================================================================
РАЗДЕЛ Б: ИНСТРУКЦИЯ ДЛЯ 32-БИТНОЙ СИСТЕМЫ (armv7l)
================================================================================

ВАЖНО: Официальный Flutter SDK не поддерживает 32-битный Linux напрямую.
Вам нужно либо перейти на 64-битную Raspberry Pi OS (рекомендуется), 
либо использовать сторонние сборки Flutter для ARM32, что сложно и нестабильно.

РЕКОМЕНДАЦИЯ: Перепрошей карту памяти на "Raspberry Pi OS Lite (64-bit)" или 
"Raspberry Pi OS with desktop (64-bit)". Это займет 15 минут, но сэкономит часы отладки.

Если вы НЕ можете сменить ОС, попробуйте установить зависимости и использовать 
предварительно скомпилированные бинарники, если они есть в репозитории проекта,
но сборка из исходников на 32-битной системе может не заработать без сложных патчей.

================================================================================
ШАГ 2: КЛОНИРОВАНИЕ ПРОЕКТА (Для всех систем)
================================================================================

cd ~
git clone https://github.com/ВАШ_НИКНЕЙМ/library_backend_cpp-main.git
cd library_backend_cpp-main

================================================================================
ШАГ 3: НАСТРОЙКА ПОДКЛЮЧЕНИЯ К БАЗЕ ДАННЫХ
================================================================================

База данных PostgreSQL находится на вашем Windows-компьютере.
1. Узнайте IP компьютера в локальной сети (в PowerShell на Windows: ipconfig).
   Пример IP: 192.168.1.55

2. Отредактируйте файл запуска, чтобы указать этот IP:
   nano run_pi.sh 
   
   # Внутри файла найдите строку export LIBRARY_PG_CONN и замените IP:
   export LIBRARY_PG_CONN="host=192.168.1.55 port=5432 dbname=library user=postgres password=123"
   
   # Сохраните: Ctrl+O, Enter, Ctrl+X

3. Убедитесь, что на Windows:
   - Запущен PostgreSQL.
   - В pg_hba.conf добавлена строка: host all all 192.168.0.0/16 scram-sha-256
   - Служба PostgreSQL перезагружена.
   - Брандмауэр Windows разрешает входящие подключения по порту 5432.

================================================================================
ШАГ 4: СБОРКА И ЗАПУСК
================================================================================

1. Сборка C++ Backend (Release режим):
   mkdir -p build
   cd build
   cmake -DCMAKE_BUILD_TYPE=Release ..
   make -j2  # Используем 2 потока, чтобы не перегреть Pi

2. Сборка Flutter Frontend:
   cd ~/library_backend_cpp-main/flutter_frontend_windows
   flutter pub get
   flutter build linux --release  # Это займет 15-30 минут

3. Запуск приложения:
   cd ~/library_backend_cpp-main
   chmod +x run_pi.sh
   ./run_pi.sh

================================================================================
ПРОБЛЕМЫ И РЕШЕНИЯ
================================================================================

1. Ошибка "Killed" при сборке:
   - Не хватает памяти. Проверьте swap командой free -h. Он должен быть > 2000M.

2. Ошибка "GLXBadContext" или черный экран:
   - Запускаете ли вы из графической оболочки? SSH без X11 forwarding не покажет окно.
   - Попробуйте: sudo apt install mesa-utils

3. Ошибка подключения к БД:
   - Проверьте пинг: ping 192.168.1.55 (ваш IP)
   - Проверьте порт: nc -zv 192.168.1.55 5432
   - Если nc пишет "Connection refused", проверьте Брандмауэр Windows.
